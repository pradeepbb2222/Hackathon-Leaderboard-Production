# Judge guide

You only see squads assigned to you. You do not see other judges' marks.

## Sign in

1. Open `/login`.
2. Use the username and password the organizer sent you.

## Score a squad

1. The list shows **Not scored**, **Draft**, or **Submitted**.
2. Open a squad.
3. Read the gate updates and open their files.
4. For each of the four criteria, pick a number from 0 to 10 and write a short comment if you want.
5. **Save draft** keeps the marks private. Drafts do not change the leaderboard.
6. **Submit score** counts the marks on the public table.

You can submit again later if the organizer has not locked scoring. The new submitted marks replace yours.
