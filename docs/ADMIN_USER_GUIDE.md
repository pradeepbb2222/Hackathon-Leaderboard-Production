# Organizer guide

You run the event from **Overview**, **Squads**, **Jury**, **Gates**, **Broadcasts**, **Audit**, and **Passes**.

## Sign in

1. Open `/login`.
2. Use the username and temporary password from the person who deployed the site.
3. The first time, set your own password.

## The control room

- **Hour buttons** jump the clock for a rehearsal or to the right phase.
- **Pause** stops the clock. **Resume** continues it.
- **Lock submissions** blocks squad saves and new judge scores.
- **Freeze leaderboard** keeps the public order still.
- **Hide scores** blanks jury marks and totals on the public table.
- **Release jury notes** lets squads read submitted comments.
- **Demo simulation (rehearsal only)** moves fake progress. Leave this **off** on event day.
- **Save weights** changes how much progress versus jury marks count. The default is 40 and 60.
- **Select top 25** marks the current top 25 as finalists.

## Squads, judges, and passes

See [EVENT_DAY_RUNBOOK.md](EVENT_DAY_RUNBOOK.md). Short version: import the CSV, print passes, add judges, assign a track.

On a squad page you can reset a password, mark a finalist, read every judge's marks, and download a ZIP of that squad's files.

## Broadcasts and audit

**Broadcasts** sends a note to every squad and the public ticker.

**Audit** lists organizer actions. Use the search box. It does not list every rehearsal simulation tick.
